Bijective Gramculator

A tool for calculating numograms with different bijective numerical bases.





Characters have values 1 through the base, in the order entered. Even the character “0” has value 1 when entered first. Gate numbers and destinations use this bijective alphabet. Syzygies pair the outermost zones inward (their values sum to base + 1); an odd base leaves the middle zone unpaired.
