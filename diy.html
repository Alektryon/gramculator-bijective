Fundamentals of the Bijective Numogram

Calculating the numogram by hand

For an alphabet of b unique characters, assign values 1 through b in the order entered. The first character always means 1. The final character means b. There is no zero digit; zero is represented by an empty numeral, and is not a zone.

Pair the outermost zones inward to form syzygies: b::1, (b−1)::2, and so on. Each pair sums to b+1 in ordinary integer values. The current runs to the zone whose value is the larger value minus the smaller. In odd bases, the middle zone is left unpaired; pairing it with itself would produce zero, which is not a zone.

The gate of a zone with value n is its triangular number n(n+1)/2. Express that number in the bijective alphabet, then add the values of its digits. Repeat, converting each sum back to bijective notation, until a single digit remains. That digit is the destination zone. Base 1 has only one zone and a gate to itself.

For example, use the base-10 alphabet 123456789A, where A means ten. Its syzygies are A::1 → 9, 9::2 → 7, 8::3 → 5, 7::4 → 3, and 6::5 → 1. Zone 4 has Gate A (value ten), which points to Zone A. Zone A has Gate 55 (value fifty-five): 5+5 = ten, written A, so it also points to Zone A.

With the alphabet 0123456789, the same values have different labels: 0 means one, 9 means ten, and 00 means eleven. Zone 3 (value four) has Gate 9 (value ten), pointing to Zone 9. Digit sums use assigned values, not the familiar meanings of the printed symbols.

Bijective notation determines the number representation. Pairing zones to sum to b+1 is the convention used here to extend the original calculator’s outermost-inward pairing rule.
